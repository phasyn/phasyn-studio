# Art exchange with Blender and Krita

The CPU environment of the art exchange with Krita and Blender (no model): Python 3.12 with the repository's media
packages and FFmpeg. Add `runtime.example.json` to the Node's runtimes; general steps:
[docs/install.md](../../../docs/install.md). The Krita side is in [plugins/krita](../../../plugins/krita/README.md).
