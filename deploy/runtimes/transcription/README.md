# Offline speech transcription runtime

The Linux x86_64 environment of the offline transcription component (faster-whisper; model: [faster-whisper-small](https://huggingface.co/Systran/faster-whisper-small)).
Install it from this directory's lock files and add `runtime.example.json` to the Node's runtimes; general steps:
[docs/install.md](../../../docs/install.md).
