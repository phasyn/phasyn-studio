# Phasyn Art Exchange for Krita

Open a Studio art package as a layered Krita document and send the revised plate back to the Studio. Install: copy
`phasyn_art.desktop` and `phasyn_art/` into Krita's `pykrita/` resource folder and enable **Phasyn Art Exchange** in
the Python Plugin Manager ([Krita guide](https://docs.krita.org/en/user_manual/python_scripting/install_custom_python_plugin.html)).
