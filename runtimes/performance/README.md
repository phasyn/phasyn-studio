# phasyn-performance

The CPU pose, depth and character-performance components of [Phasyn Studio](https://github.com/phasyn/phasyn-studio). The models are not included:
[MediaPipe pose and face landmarkers](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker) (Google) and
[MiDaS v2.1](https://github.com/isl-org/MiDaS) (MIT). Setup: [docs/install.md](../../docs/install.md) and the runtime environment in `deploy/runtimes/performance-cpu/`.
