# phasyn-segmentation

The interactive object-mask component of [Phasyn Studio](https://github.com/phasyn/phasyn-studio), built on SAM 2. The weights are not included; see
[SAM 2.1 hiera-tiny](https://huggingface.co/facebook/sam2.1-hiera-tiny) for the model and its licence.
Setup: [docs/install.md](../../docs/install.md) and the runtime environment in `deploy/runtimes/segmentation/`.
