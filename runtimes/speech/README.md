# phasyn-speech

The dialogue voice component of [Phasyn Studio](https://github.com/phasyn/phasyn-studio) (Qwen3-TTS CustomVoice). The weights are not included; see
[Qwen3-TTS-12Hz-1.7B-CustomVoice](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice) for the model and its
licence. Setup: [docs/install.md](../../docs/install.md) and the runtime environment in `deploy/runtimes/speech/`.
