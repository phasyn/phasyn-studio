# phasyn-wan-edit

The Wan 2.1 VACE video generation and editing components of [Phasyn Studio](https://github.com/phasyn/phasyn-studio). The weights are not included; see
[Wan2.1-VACE-1.3B](https://huggingface.co/Wan-AI/Wan2.1-VACE-1.3B-diffusers) for the model and its licence.
Setup: [docs/install.md](../../docs/install.md) and the runtime environment in `deploy/runtimes/wan-edit-x86_64/`.
