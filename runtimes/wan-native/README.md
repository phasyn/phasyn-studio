# phasyn-wan-native

The Wan 2.2 speech-driven and performance video components of [Phasyn Studio](https://github.com/phasyn/phasyn-studio). The weights are not included; see
[Wan2.2-S2V-14B](https://huggingface.co/Wan-AI/Wan2.2-S2V-14B) and [Wan2.2-Animate-14B](https://huggingface.co/Wan-AI/Wan2.2-Animate-14B)
for the models and their licences. Setup: [docs/install.md](../../docs/install.md) and the runtime environment in `deploy/runtimes/wan-native/`.
